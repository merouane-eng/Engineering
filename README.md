# Engineering Web

Application web React + Node.js pour les modules Engineering.

## Démarrage

```powershell
cd web
npm.cmd install
npm.cmd run dev
```

- Interface : http://localhost:5173
- API : http://localhost:5178/api

L'API utilise directement `data.db` à la racine du projet. Les utilisateurs sont les mêmes que l'application desktop. Le rôle `admin`, les superviseurs et les techniciens sont contrôlés par l'API.
